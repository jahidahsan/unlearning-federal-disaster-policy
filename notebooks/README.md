
# Notebook Directory

Only notebooks with stored outputs are included.

- `current/` — latest completed output-bearing notebook.
- `historical/completed/` — completed execution records that were later superseded.
- `historical/incomplete/` — output-bearing partial runs retained because they document a substantive stage or execution failure.

All outputless source notebooks, including the unfinished LangChain notebook, were discarded from this snapshot. See `manifests/notebook_execution_status.csv` for the complete audit.
