
# Legacy Archive

This directory retains deduplicated historical artifacts that are relevant to the project but are not canonical current inputs or immutable completed experiment packages.

`legacy_exports/desktop/` was considered higher priority than `legacy_exports/downloads/` when exact duplicates existed. Original filenames and folder context were preserved as much as possible. These files include historical prediction tables, result workbooks, presentations, annotated PDFs, and intermediate datasets.

Presence in the archive does not mean a file contains final or team-approved results. Use `manifests/repository_file_manifest.csv` and the experiment history before citing an archived artifact.

August team updates were delivered as Excel workbooks, so the absence of an August PowerPoint is intentional. PowerPoint files retained here are earlier July materials or alternate historical drafts.
